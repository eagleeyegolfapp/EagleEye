# EagleEye legal / support pages

Static pages for App Store Connect and public support.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Simple landing |
| `privacy.html` | Privacy Policy (App Store **Privacy Policy URL**) |
| `support.html` | Support (App Store **Support URL**) |

Contact email on all pages: **eagleeyegolfapp@gmail.com**

## GitHub Pages

1. Create a new **public** repository (e.g. `eagleeye-legal`).
2. Upload these files to the repo root (or push this folder).
3. Repo **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` (or `master`), folder: **/ (root)**
4. After a minute, open:

```text
https://YOUR_GITHUB_USERNAME.github.io/eagleeye-legal/
https://YOUR_GITHUB_USERNAME.github.io/eagleeye-legal/privacy.html
https://YOUR_GITHUB_USERNAME.github.io/eagleeye-legal/support.html
```

If the repo is named `YOUR_USERNAME.github.io`, URLs omit the `/eagleeye-legal` path segment.
