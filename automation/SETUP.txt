EAGLEEYE SOCIAL AUTOMATION — START TO FINISH
============================================

What this system does, every morning, with no clicking, even if this Mac is off:
  1. GitHub Actions wakes in the cloud (or you tap Run workflow).
  2. Machine A researches official golf news, finds official URLs.
  3. It POSTs a scheduled job to Late. Late is also in the cloud.
  4. Late publishes to X + Instagram + Reddit at the Eastern time, Mac or no Mac.
  5. You still do follows / DMs by hand.

GitHub Actions is the only automatic publisher. This Mac does not auto-post
(launchd is off). Closing the dashboard does not stop the cloud runner.
Dashboard "Run" / Spotlight are manual overrides only.

What it will NOT do (on purpose):
  - Reply, follow, or DM. You still do that as a person.
  - Invent fake EagleEye UI. Product stills are brand frames or real screenshots.
  - Download PGA TOUR / Golf Channel files to re-upload.
  - Bid fake news. If golf-world news is thin, it uses an evergreen golf still.
